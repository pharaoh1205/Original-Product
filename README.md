# Original-Product
①課題<br>
SNSやWebで「行きたい！」と思って保存した店が、スクショや写真フォルダに埋もれて、その後活用されない。
さらに、スクショした直後に登録しないと「なぜこの店をスクショしたのか」自体を忘れてしまう

②その課題をどう解決するか<br>
「スクショ → 共有 → 自動登録」だけで、行きたい店リストを作れるようにする
「行きたい店を忘れずに記録し、実際に行くことにつなげる」


③ Googleカレンダーとの差別化<br>
Googleカレンダーは今回のアプリの直接的な競合ではない

Googleカレンダーの主目的は、「いつ・何をするか」を管理
一方、このアプリの主目的は、「行きたい店を忘れずに蓄積し、実際に行くことにつなげる」

最大の差別化<br>
スクショした瞬間の入力コストを極限まで下げる
Googleカレンダー＝予定管理
このアプリ＝行きたい店・食体験のストック管理

ーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーーー
●アプリとして最低限必要なメイン機能
MVP（最初に作る最低限のバージョン）は以下の6機能

1. スクショ共有・即保存
最重要機能
スクショ → 共有 → アプリで即保存
解析を待たず、まず画像を保存する。

⸻
2. 店舗情報の自動解析
スクショから、
* 店名
* 住所などの位置情報をOCR/Visionで解析
その情報を使ってGoogle Mapsから店舗候補を取得
* 候補1件 → 自動登録
* 複数候補 → ユーザーが選択
* 候補なし → 手動で店名入力

⸻
3. 「行きたい店」一覧＋マップ
登録した店舗を
* 一覧
* 地図
の両方で確認できるようにする。

店舗をタップするとポップアップで、
* スクショ
* 店名
* 住所
* 営業時間
* メモ
を確認できる。
⸻

4. 行った店への変更
「行った店」に変更すると登録時のスクショだけ削除。
メモなどの店舗情報は保持。

行った店では、
* 写真を1枚追加可能
* 写真は任意
* 後から変更可能
⸻

5. 自分の百名店
行った店から「百名店に追加」できる

* 最大100店舗
* 写真必須
* 写真は1枚
* 百名店専用一覧
* 百名店専用マップ
* 登録した新しい順

100店舗集めること自体を、アプリを使い続ける動機に
⸻

6. 店舗の状態管理・削除
店舗を行きたい店 ⇄ 行った店 → 百名店という形で管理

また、
* 行った店から行きたい店に戻す
* 百名店から行った店に戻す
* 店舗を完全削除する
といった操作も可能にする。

削除時には必ず確認を出す。
⸻
MVPとしての一番重要な部分

最初から全部を豪華にする必要はありません。
このアプリのコア体験は、
SNSで店を発見
↓
スクショ
↓
共有
↓
ほぼ何もしなくても「行きたい店」に登録される
↓
後から地図を見て「ここ行きたい」と思える
↓
行ったらチェック
↓
気に入った店を自分の百名店にする

この一連の体験です。

特に**「スクショ直後の共有→即保存」と「百名店」**が、このアプリの特徴としてかなり強い部分だと思います。
